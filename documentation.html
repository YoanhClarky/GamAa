Documentation

Tout ce qu'il faut savoir pour lancer le projet en local et ajouter un nouveau jeu dans les règles de l'art.

Structure du repo

Un dossier par jeu, un fichier HTML unique à l'intérieur. Nom de dossier et de fichier en minuscules, avec des tirets.

gamAa/
├── index.html            // accueil + grille des jeux
├── apropos.html
├── contribuer.html
├── documentation.html
├── roadmap.html
├── communaute.html
├── assets/
│   ├── logo.png
│   └── icon.png
└── corporate-dodger.html  // un fichier HTML autonome par jeu

Lancer le projet en local

Aucune installation nécessaire. Clone le dépôt et ouvre index.html directement dans un navigateur, ou lance un petit serveur local pour naviguer confortablement entre les pages.

Template de base

Copie ce squelette pour démarrer un nouveau jeu, puis adapte-le avec la charte graphique de gamAa.

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Nom du jeu</title>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body {
      font-family: "Segoe UI", Roboto, Arial, sans-serif;
      background: #1c2b39;
      color: #fff;
      min-height: 100vh;
      display: flex;
      flex-direction: column;
      align-items: center;
      justify-content: center;
    }
    /* ... styles du jeu ... */
  </style>
</head>
<body>
  <h1>Nom du jeu</h1>
  <div id="gameWrap"><!-- canvas ou DOM du jeu --></div>

  <script>
    // logique du jeu, tout en JavaScript natif
  </script>
</body>
</html>

Charte graphique

Navy — #1c2b39
Ambre — #f4b400

Typographie : police système (Segoe UI, Roboto, Arial, sans-serif), pas de police externe à charger.

Règle de simplicité visuelle : peu d'éléments à l'écran, priorité à la lisibilité et à la jouabilité immédiate. Pas d'emoji, design flat, sans ombres superflues.
