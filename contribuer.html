Contribuer

gamAa grandit grâce à ses contributeurs. Ajouter un jeu, corriger un bug, proposer une idée : chaque contribution compte et reste visible sur la plateforme.

Proposer un jeu

  1. Fork le dépôt GitHub.
  2. Crée un nouveau fichier HTML pour ton jeu, dans son propre dossier.
  3. Respecte le template et la charte graphique (voir Documentation).
  4. Ouvre une pull request avec une courte description de ton jeu.

Règles de style à respecter

  • Palette de couleurs : navy #1c2b39 et ambre #f4b400.
  • Pas d'emoji dans l'interface.
  • Design flat, sans ombres ni effets superflus.
  • Un fichier HTML autonome par jeu (CSS et JS inclus).
  • Écran adapté au mobile dès la première version.

Niveau technique requis

Des bases en HTML, CSS et JavaScript suffisent. Aucun framework n'est obligatoire.

Une idée, sans coder

Pas envie ou pas capable de coder ? Ouvre une issue sur le dépôt GitHub avec ton idée de jeu. Un développeur de la communauté peut s'en emparer.

Crédit

Chaque contributeur est listé et remercié dans le dépôt et sur la page Communauté.
