Contribuer

gamAa grandit grâce à ses contributeurs. Ajouter un jeu, corriger un bug, proposer une idée : chaque contribution compte et reste visible sur la plateforme.

Proposer un jeu

  1. Fork le dépôt GitHub.
  2. Duplique le dossier games/_template/, renomme la copie avec ton nom (ex. games/ton-nom/).
  3. Dans ce dossier, renomme mon-jeu.html avec le nom de ton jeu, puis modifie le <title>, les balises <meta name="game:*"> et le code du jeu, en respectant la charte graphique (voir Documentation).
  4. Remplis aussi profile.json dans ton dossier (nom, courte bio, liens GitHub / site / réseaux) : c'est ce qui alimente ta fiche sur la page Communauté. Laisse vide ce que tu ne veux pas partager.
  5. Tu peux lancer node scripts/build-games.js en local pour vérifier que ton jeu et ton profil apparaissent bien, mais n'ajoute pas assets/games.js à ton commit : la CI le régénère toute seule après le merge.
  6. Ouvre une pull request qui ne touche que ton dossier games/ton-nom/, avec une courte description de ton jeu.

Règles de style à respecter

  • Palette de couleurs : navy #1c2b39 et ambre #f4b400.
  • Pas d'emoji dans l'interface.
  • Design flat, sans ombres ni effets superflus.
  • Un fichier HTML autonome par jeu (CSS et JS inclus), rangé dans ton dossier games/ton-nom/.
  • Écran adapté au mobile dès la première version.

Niveau technique requis

Des bases en HTML, CSS et JavaScript suffisent. Aucun framework n'est obligatoire.

Une idée, sans coder

Pas envie ou pas capable de coder ? Ouvre une issue sur le dépôt GitHub avec ton idée de jeu. Un développeur de la communauté peut s'en emparer.

Crédit

Chaque contributeur est listé et remercié dans le dépôt et sur la page Communauté.
